# Roadmap

This page is for anyone who wants to know what's planned for **Vortex** and
where to follow the work. It links the GitHub project that tracks the
features and bug fixes on their way, and lists the goals the maintainers are
working toward.

The [Vortex 1.x project](https://github.com/orgs/drevops/projects/2) on
GitHub tracks the planned work. Its views show the following:

- [Development](https://github.com/orgs/drevops/projects/2/views/1) shows
  the work in progress as a board.
- [Current release](https://github.com/orgs/drevops/projects/2/views/2)
  lists the priorities for the current release.
- [Next release](https://github.com/orgs/drevops/projects/2/views/3) lists
  the priorities for the next release.
- [2.x](https://github.com/orgs/drevops/projects/2/views/4) and
  [3.x](https://github.com/orgs/drevops/projects/2/views/5) list the
  priorities for those major versions.

We plan a release every month, but the schedule can shift with the scope of
the features and the volume of bug fixes in each one.

## Current goals

The maintainers are working toward these goals:

- [Support for DDEV](https://github.com/drevops/vortex/issues/949)
- [Support for Lando](https://github.com/drevops/vortex/issues/815)

## Future goals

These goals are further out:

- Integration with [Upsun](https://upsun.com/)
- Support for Cypress and Drupal Test Traits
- A **Vortex** Dashboard as a single place for managing projects
