# Roadmap

The project boards on GitHub show the features and bug fixes on their way:

- [Project development
  board](https://github.com/orgs/drevops/projects/2/views/1) - the work in
  progress.
- [Project planning
  board](https://github.com/orgs/drevops/projects/2/views/2) - the
  priorities for the current release. Separate views plan the
  [next release](https://github.com/orgs/drevops/projects/2/views/3),
  [2.x](https://github.com/orgs/drevops/projects/2/views/4), and
  [3.x](https://github.com/orgs/drevops/projects/2/views/5).

We plan a release every month, but the schedule can shift with the scope of
the features and the volume of bug fixes in each one.

## Current goals

1. [Support for DDEV](https://github.com/drevops/vortex/issues/949)
2. [Support for Lando](https://github.com/drevops/vortex/issues/815)

## Future goals

1. Integration with [Upsun](https://upsun.com/).
2. Support for Cypress and Drupal Test Traits.
3. Support for accessibility tools.
4. A **Vortex** Dashboard as a single place for managing projects.
