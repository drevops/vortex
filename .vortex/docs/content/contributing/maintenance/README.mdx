# Maintenance

This section is for people who maintain **Vortex** itself: the template,
the installer, the tooling package, the documentation, and the releases. If
you're building a site from **Vortex**, the rest of the documentation is
where you want to be.

The maintenance tooling lives in `.vortex/`, a directory the installer
leaves out of every consumer site. The `ahoy` commands on these pages come
from `.vortex/.ahoy.yml`, so run them from `.vortex/`, or from the
repository root with `ahoy --file .vortex/.ahoy.yml <command>`.
