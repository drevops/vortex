# Contributing

**Vortex** is an open source project that welcomes contributions of every kind from developers and non-technical users. You can fix a bug, propose a feature, or improve the documentation.

## I've discovered a problem

Check whether the problem has already been reported in the [issue queue](https://github.com/drevops/vortex/issues), and report it there if it hasn't.

## I want to suggest a feature or an idea

[Submit your idea](https://github.com/drevops/vortex/issues) to the same issue queue. We read and review every idea for improving **Vortex**, though not every suggestion is accepted.

## I want to submit a change

Changes come in as pull requests against the
[`drevops/vortex`](https://github.com/drevops/vortex) repository. The
[Maintenance](maintenance/README.mdx) section documents how the template, the
installer, and this documentation site are developed and tested, so your change
arrives with the right tests and fixtures.

## Talk to us on Slack

You can also talk to us about your idea in the `#drevops` channel of the Drupal Slack.
