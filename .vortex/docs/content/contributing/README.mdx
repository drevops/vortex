# Contributing

**Vortex** is an open source project, and it welcomes contributions of every
kind, whether you write code or not. You can fix a bug, propose a feature,
or improve the documentation you're reading right now.

## I've discovered a problem

Check whether someone has already reported it in the
[issue queue](https://github.com/drevops/vortex/issues). If nobody has, open
a new issue there and describe what you saw.

## I want to suggest a feature or an idea

[Submit your idea](https://github.com/drevops/vortex/issues) to the same
issue queue. We read and review every idea for improving **Vortex**, though
we can't accept every suggestion.

## I want to submit a change

Send it as a pull request against the
[`drevops/vortex`](https://github.com/drevops/vortex) repository. Target
`main` for the current major version, or `2.x` for work on the upcoming one
(see [Release > Branch strategy](maintenance/release.mdx#branch-strategy)).

The [Maintenance](maintenance/README.mdx) section explains how we develop
and test the template, the installer, the tooling package, and this
documentation site. Read it first, so your change arrives with the right
tests and fixtures.

## Talk to us on Slack

You can also talk to us about your idea in the
[`#vortex-project-template`](https://drupal.slack.com/archives/CRE86HQTW)
channel of the Drupal Slack.
