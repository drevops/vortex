# Tools

**Vortex** comes with a set of tools to help you develop and maintain your
Drupal project. Each tool ships with its own configuration file, adjusted to
work for Drupal projects out of the box.

Many of the tools are selectable when you install **Vortex**, and the linters
and scanners run in the continuous integration pipeline, where each can be
individually allowed to fail via its `VORTEX_CI_<TOOL>_IGNORE_FAILURE`
variable - see [Ignore tool failures](../continuous-integration/README.mdx#ignore-tool-failures).

## Environment and runtime

| Name                     | Description                                                    |
|--------------------------|----------------------------------------------------------------|
| [Ahoy](ahoy.mdx)         | CLI command wrapper for project tasks                          |
| [Docker](docker.mdx)     | Containerized services for local development and hosting       |
| [Pygmy](pygmy.mdx)       | Local reverse-proxy and email catcher for the container stack  |
| [Doctor](doctor.mdx)     | Check project requirements and retrieve environment information |
| [Drush](drush.mdx)       | Command line shell and scripting interface for Drupal          |

## Code quality

| Name                                   | Description                                                 |
|----------------------------------------|-------------------------------------------------------------|
| [PHPCS](phpcs.mdx)                     | Check that PHP code adheres to coding standards             |
| [PHPStan](phpstan.mdx)                 | Static analysis for PHP                                     |
| [Rector](rector.mdx)                   | Automated PHP refactoring and upgrades                      |
| [ESLint](eslint.mdx)                   | Lint JavaScript in custom modules, with Prettier integration |
| [Stylelint](stylelint.mdx)             | Lint CSS in custom modules and the theme                    |
| [Twig CS Fixer](twig-cs-fixer.mdx)     | Check Twig templates against coding standards               |
| [Gherkin Lint](gherkin-lint.mdx)       | Lint Behat feature files                                    |
| [SDC Devel](sdc-devel.mdx)             | Validate Single Directory Components in the theme           |
| [DCLint](dclint.mdx)                   | Lint Docker Compose files                                   |
| [Hadolint](hadolint.mdx)               | Lint Dockerfiles                                            |
| [Gitleaks](gitleaks.mdx)               | Detect committed secrets like passwords, API keys, and tokens |
