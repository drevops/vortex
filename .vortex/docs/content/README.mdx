**Vortex** is a Drupal project template for building and deploying Drupal
sites. This introduction is for anyone evaluating it or about to start a
project with it. It covers why the template exists and what it's made of.
It ends with links to install it, get help and contribute.

A **Vortex** project comes with the following parts. They're configured to
work together, so your team starts on features instead of infrastructure:

- A containerized local environment
- Automated testing and code quality tools
- Continuous integration pipelines for GitHub Actions or CircleCI
- Integrations with the Acquia and Lagoon hosting platforms

Every **Vortex** project shares the same structure and tooling. A developer
who has worked on 1 project knows their way around the next.

Renovate opens pull requests that update the tools the template ships.
Automated tests in the template repository check every change to the
template. The tests lower the risk of an update breaking your project and
keep your project easier to maintain over time.

## Why Vortex exists

Setting up a Drupal project takes time, and every setup comes out a little
different:

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>⏱️ Developers lose hours or days setting up their local, continuous
    integration and hosting environments</li>
  <li>⚠️ Inconsistent setups cause false negatives that erode trust in
    the tools</li>
  <li>🔌 Poorly understood third-party services slow integration and
    troubleshooting</li>
  <li>📉 Poor onboarding documentation slows new team members down</li>
</ul>

Those gaps add up to the following:

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>😩 Developer frustration and burnout</li>
  <li>⏳ Project delays and missed deadlines</li>
  <li>💸 Unplanned costs and budget overruns</li>
</ul>

We built **Vortex** to solve these problems with a ready-to-use foundation
for developing and maintaining Drupal projects.

### 📦 Template

The template includes the following:

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>💧 A pre-configured Drupal project structure with module, theme and
    test boilerplate</li>
  <li>🧰 Pre-configured tools for code quality checks and automated
    testing</li>
  <li>🐳 Docker-based environment for local development and cloud
    hosting</li>
  <li>☁️ Built-in support for Acquia and Lagoon cloud hosting platforms</li>
  <li>🏗️ Continuous integration using GitHub Actions or CircleCI</li>
  <li>📖 Project documentation</li>
</ul>

➡️ See [Features](/docs/features) and [Architecture](/docs/architecture)

### 📖 Documentation

The documentation comes in 3 parts:

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>🌐 Centralized documentation on this site</li>
  <li>🗂️ Scaffolded structure for project-specific docs</li>
  <li>📋 Project README with local setup steps</li>
</ul>

### 🎛️ Installer

The installer does the following:

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>📦 Adds boilerplate for the features you select</li>
  <li>🏗️ Renames files and replaces strings during installation</li>
  <li>🔄️ Updates existing installations to a newer boilerplate version
    when you run <code>ahoy update-vortex</code></li>
  <li>🔌 Runs as a standalone CLI application that scripts and AI
    agents can drive with prepared answers, a prompt schema and a
    validation mode</li>
</ul>

➡️ See [Installation](/docs/installation) and
[Updating Vortex](/docs/updating-vortex)

## 🚀 Quick start

The installer needs PHP 8.3 or later, `curl`, `git`, `tar` and `composer`.
Building the site needs Docker, Pygmy and Ahoy.

Run the installer in an empty directory and answer its prompts:

```shell
curl -SsL https://www.vortextemplate.com/install > installer.php && php installer.php
```

After a successful installation, the installer shows a
**Finished installing Vortex** box before it offers to build the site.

➡️ See [Installation](/docs/installation) for the full requirements and
