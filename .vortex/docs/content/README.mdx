**Vortex** is a Drupal project template for building and deploying Drupal
sites. You get a containerized local environment, automated testing and code
quality tools, continuous integration pipelines for GitHub Actions or
CircleCI, and integrations with the Acquia and Lagoon hosting platforms. It
all arrives configured and working together, so your team starts on features
instead of setting up infrastructure.

Every **Vortex** project shares the same structure and tooling, so
developers joining an existing one get up to speed quickly. Once you know
one, you know your way around the next.

The template is actively maintained and kept in step with the latest
releases of the tools it ships. Automated tests check every change to the
template, which lowers the risk of an update breaking your project and keeps
it easier to maintain over time.

## Why Vortex exists

Setting up a Drupal project takes time, and every setup comes out a little
different:

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>⏱️ Developers lose hours or days setting up their local, continuous
    integration, and hosting environments</li>
  <li>⚠️ Inconsistent setups cause false negatives that erode trust in
    the tools</li>
  <li>🔌 Poorly understood third-party services slow integration and
    troubleshooting</li>
  <li>📉 Poor onboarding documentation slows new team members down</li>
</ul>

Those gaps add up to:

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>😩 Developer frustration and burnout</li>
  <li>⏳ Project delays and missed deadlines</li>
  <li>💸 Unplanned costs and budget overruns</li>
</ul>

We built **Vortex** to solve these problems with a ready-to-use foundation
for developing and maintaining Drupal projects.

### 📦 Template

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>💧 A pre-configured Drupal project structure with module, theme, and
    test boilerplate</li>
  <li>🧰 Pre-configured tools for code quality checks and automated
    testing</li>
  <li>🐳 Docker-based environment for local development and cloud
    hosting</li>
  <li>☁️ Built-in support for Acquia and Lagoon cloud hosting platforms</li>
  <li>🏗️ Continuous integration using GitHub Actions or CircleCI</li>
  <li>📖 Project documentation</li>
</ul>

➡️ See [Features](/docs/features) and [Architecture](/docs/architecture)

### 📖 Documentation

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>🌐 Centralized documentation at https://www.vortextemplate.com</li>
  <li>🗂️ Scaffolded structure for project-specific docs</li>
  <li>📋 Project README with local setup steps</li>
</ul>

### 🎛️ Installer

<ul style={{ listStyle: 'none', paddingLeft: 0 }}>
  <li>📦 Adds boilerplate for the features you select</li>
  <li>🏗️ Renames files and replaces strings during installation</li>
  <li>🔄️ Updates existing installations to a newer boilerplate version</li>
  <li>🔌 Standalone CLI application extensible with an API to support new
    integrations</li>
</ul>

## 🚀 Quick start

Run the installer in an empty directory and answer its prompts:

```shell
curl -SsL https://www.vortextemplate.com/install > installer.php && php installer.php
```
