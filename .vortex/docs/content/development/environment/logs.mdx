# Logs

Logs are where you find out why a container won't start or why a page
throws an error. Each container writes its output to Docker's log, and
`ahoy logs` shows it by running `docker compose logs` with any arguments you
add. Drupal records its own messages in the watchdog log, which Drush reads.

`ahoy up` scans the container logs right after starting the stack and fails
if any container has logged `[Error]`. When that happens, or when
[Doctor](doctor.mdx) reports a container that isn't running, start here:

<Tabs>
  <TabItem value="ahoy" label="Ahoy" default>
    ```shell
    # Show container logs
    ahoy logs
    # Check recent logs of a single container
    ahoy logs -- --tail=50 cli
    # View Drupal watchdog logs
    ahoy drush watchdog:show --count=20
    ```
  </TabItem>
  <TabItem value="docker-compose" label="Docker Compose">
    ```shell
    # Show container logs
    docker compose logs
    # Check recent logs of a single container
    docker compose logs --tail=50 cli
    # View Drupal watchdog logs
    docker compose exec cli drush watchdog:show --count=20
    ```
  </TabItem>
</Tabs>
